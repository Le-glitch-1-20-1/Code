# Projet-Scratch

Projets réalisés avec [Scratch](https://scratch.mit.edu/) (fichiers `.sb3`, ouvrables avec
l'éditeur Scratch en ligne ou l'application [Scratch Desktop](https://scratch.mit.edu/download)).

---

## Contenu

```
Projet-Scratch/
├── dessin pour papa.sb3	← projet de dessin
└── jeu 2/					← itérations successives d'un jeu
    ├── Projet Scratch 1.sb3
    ├── Projet Scratch 2.sb3
    ├── ...
    └── Projet Scratch 9.sb3
```

- **`dessin pour papa.sb3`** : petit projet de dessin/animation.
- **`jeu 2/`** : versions successives (1 à 9) d'un même projet de jeu, chaque fichier
  correspondant à une étape d'avancement.

## Utilisation

Ouvrir les fichiers `.sb3` directement dans l'[éditeur Scratch en ligne](https://scratch.mit.edu/projects/editor/)
(bouton "Charger depuis l'ordinateur") ou dans Scratch Desktop.

## Auteurs

Projets réalisés dans le cadre de projets personnels.
