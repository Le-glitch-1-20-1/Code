# Projet-C

Regroupement de projets en langage C (et un projet JS/Electron) développés
individuellement.

---

## Sous-projets

| Projet | Description | Techno |
|---|---|---|
| [`ascii-art/`](./ascii-art) | Générateur de texte ASCII façon FIGlet, avec gestion de polices `.flf`/`.tlf` | C |
| [`game-of-life/`](./game-of-life) | Implémentation du Jeu de la Vie de Conway avec rendu graphique temps réel | C + raylib |
| [`librarie/`](./librarie) | Application de bureau de gestion de bibliothèque personnelle | JS + Electron |

Chaque sous-projet possède son propre `README.md` avec les instructions détaillées
de compilation/installation et d'utilisation.

## Structure

```
Projet-C/
├── ascii-art/		← générateur ASCII art (C)
├── game-of-life/	← jeu de la vie de Conway (C + raylib)
└── librarie/		← gestionnaire de bibliothèque (Electron)
```

## Auteurs

Projets réalisés dans le cadre de l'École 42.
